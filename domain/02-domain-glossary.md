# 02. Domain glossary

- **Заказ (Order)** — сущность с `id` и описательными полями.
- **Intent** — бизнес-описание задачи (`docs/intent/`).
- **Change** — изменение в OpenSpec (`openspec/changes/<id>/`).
- **Идентификатор заказа (`id`)** — UUID, генерируется сервисом при создании заказа, неизменяем.
- **Имя клиента (`customerName`)** — непустая строка с условным именем клиента заказа; реальных персональных данных не содержит.
- **Позиция заказа (Order item)** — элемент списка `items` заказа: `productName` (непустая строка), `quantity` (целое число > 0), `price` (десятичное число >= 0).
- **Статус заказа (`status`)** — одно из значений `NEW`, `CONFIRMED`, `CANCELLED`; по умолчанию `NEW`.
- **Время создания (`createdAt`)** — момент создания заказа, неизменяем; задаёт порядок заказов в списке.
